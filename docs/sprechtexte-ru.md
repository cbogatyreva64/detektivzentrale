# Sprechtexte auf Russisch (Д)

Die russischen Fassungen zu [`sprechtexte.md`](sprechtexte.md). Der Aufbau ist derselbe: fester Anfang, Fall, fester Schluss.
**Alles in [eckigen Klammern] an deine echten Verstecke anpassen.** Die Reime sind auf Russisch neu gedichtet, keine wörtlichen Übersetzungen.

- Die Texte sprechen einen Jungen an („ты раскрыл“, „готов“). Für ein Mädchen: раскрыла, готова.
- Statt „Ende der Nachricht“ heißt es „Конец связи!“ („Ende der Funkverbindung“). Das passt zum Funk-Effekt.
- Fund-Symbole: Lego = кубик Лего, Experiment = пробирка, Pixi-Buch = книжка.

## Bausteine

**Anfang (jeden Tag gleich):**
> Внимание, внимание! Говорит Детективный центр. Новое дело для детектива [Имя]!

**Schluss Lego- und Pixi-Tage:**
> На месте находки приклеена бумажка с числом. Набери это число на кодовом замке. Удачи, детектив! Конец связи!

**Schluss Experiment-Tage:**
> На месте находки приклеена бумажка с числом. Набери его на кодовом замке. А когда опыт получится,
> сфотографируй его для своего дневника исследователя! Удачи, детектив! Конец связи!
